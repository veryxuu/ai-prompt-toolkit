# AI Prompt Toolkit

A simple open-source toolkit for creating, organizing, searching, and improving AI prompts.

## Features

- Store prompts in a simple JSON file
- Search prompts by title or content
- Add your own prompts
- Easy to use and modify
- No external dependencies required

## Requirements

- Python 3.8 or newer

## Usage

Clone the repository:

```bash
git clone https://github.com/veryxuu/ai-prompt-toolkit.git
cd ai-prompt-toolkit
python prompt_tool.py
